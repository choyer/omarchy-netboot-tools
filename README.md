# Omarchy Netboot Tools & Resources

A collection of assorted tools & resources pertaining to netbooting Omarchy, useful for network deployments.

Originally born out of a desire to test & troubleshoot vintage Intel Apple Mac (iMac, MacBook, MacBook Pro, Mac Pro, Mac Mini) compatibility and support.

## My Netboot Setup

TrueNAS running [netbootxyz](https://netboot.xyz/) via custom yaml compose config. On an isolated VLAN'd network. DHCP network boot enabled via PFSense.
